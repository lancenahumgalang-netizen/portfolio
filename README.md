# Lance Nahum Galang | Home Page

A one-page portfolio: portrait on the left of the hero, intro, quick facts, education and contact details, with a light/dark switch.

## Files
| File | What it is | Edit it? |
|---|---|---|
| `data.js` | Your details: intro, quick facts, education, contact | **Yes** |
| `index.html` | The page that loads everything | Rarely |
| `app.js` | Builds the page from `data.js` | No |
| `styles.css` | Colors, fonts and layout | Only to change the look |
| `images/` | Put your photo here | Add files |

## Your photo
Your profile picture is `me.jpg` (set in `data.js` as `photo`). Replace the file to change it.

## Other edits
- Facebook link: paste your profile address in `facebook.link` in `data.js`.
- Resume button: set `resume: "images/resume.pdf"`.
